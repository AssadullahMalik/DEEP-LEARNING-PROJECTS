# 🐱 Cat vs Dog Classifier

A Convolutional Neural Network (CNN) project for classifying images into two categories:

- 🐱 Cat
- 🐶 Dog

## Technologies Used

- Python
- TensorFlow
- Keras
- NumPy
- Matplotlib
- CNN

## Model

The model uses convolutional layers, pooling layers, and fully connected layers to classify images.

## Dataset

The project uses a Cat vs Dog image dataset.

## Project Notebook

The complete implementation is available in:

`cat_vs_dog classifier.ipynb`
